# 中华人民共和国民法典 · 法条检索 Skill

本 skill 将《民法典》全文（按编拆分）作为可检索的知识源，用于**精确查找并引用法条**，而非生成法律意见。

## 版本与来源

- 通过：2020-05-28 第十三届全国人大第三次会议
- 施行：2021-01-01
- 结构：7 编 + 附则，共 **1260 条**
- 底本：全国人大官网公布的官方 PDF（wb.flk.npc.gov.cn），经文本抽取并按编拆分

> 注意：法律可能被后续立法修订。若涉及最新有效性，请以全国人大/司法部最新公布为准。本 skill 数据为 2021 施行版快照。

## ⚠️ 免责声明（必须前置）

本 skill 仅用于**法条检索、学习与参考**。
- **不构成法律意见，不代表律师或法律机构观点。**
- 对具体案件的处理建议、诉讼策略、风险评估，请咨询**执业律师**。
- 回答中涉及用户自身权利义务时，必须附上上述提示。

## 使用流程（按需读取，不要一次读全本）

1. **判断所属编**：根据用户问题，对照下方「编 → 主题」映射到对应章节文件。
2. **读取章节文件**：用 Read 工具打开 `chapters/编X_名称.md`（路径相对于本 skill 目录）。
3. **定位条文**：在文件中按条号或关键词找到对应「第X条」，**原文引用**该条内容。
4. **跨编问题**：如问题涉及多个编（例如「买房违约又想离婚」涉及合同编+婚姻家庭编），分别读取相关文件。
5. **找不到时**：如实说明「未在《民法典》中找到直接对应的条文」，可提示可能相关的编章方向，**严禁编造条号或条文内容**。

## 引用格式

引用时必须标注编与条号，例如：

> 《民法典》第 1077 条（婚姻家庭编）规定：「自婚姻登记机关收到离婚登记申请之日起三十日内，任何一方不愿意离婚的，可以向婚姻登记机关撤回离婚登记申请。」

- 条号用中文数字（与原文一致）。
- 尽量摘引与问题最相关的整条或整款，不要断章取义。
- 若条文有但问题不在适用范围，应说明限制条件。
