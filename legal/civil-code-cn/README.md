# civil-code-cn · 民法典法条检索 Skill

把《中华人民共和国民法典》全文转成一个可被 Agent 直接调用的 Skill，用于**精确检索并引用法条**，而不是泛泛生成法律意见。

## 这个 Skill 能做什么

- 回答中国民事法律问题（合同纠纷、婚姻离婚、继承、物权、人格权侵权、诉讼时效等）。
- 按「编」定位、原文引用具体条文，例如：问「离婚冷静期」，它会读出《民法典》**第 1077 条**并原文引用。
- 覆盖**总则、物权、合同、人格权、婚姻家庭、继承、侵权责任**七编及附则，共 **1260 条**。

## 数据来源与版本

- 底本：全国人民代表大会官网公布的官方 PDF（`wb.flk.npc.gov.cn`）。
- 通过：2020-05-28 第十三届全国人大第三次会议；施行：2021-01-01。
- 本仓库为 **2021 施行版快照**。法律如被后续立法修订，请以官方最新公布为准，并重跑抽取更新。

## 运行机制（简述）

1. 用户提问 → Agent 加载 `SKILL.md` 的指令。
2. 按「编→主题速查表」判断问题归属哪一编。
3. 用 Read 打开对应的 `chapters/编X_名称.md`（只加载相关编，而非整本 1260 条）。
4. 按条号 / 关键词定位「第 X 条」，原文引用并标注编与条号。
5. 找不到时如实说明，**不编造条号或条文**。

> 这是「文件级按需检索」，不是向量 RAG——对法律这种常能定位到编、且要求条号精确的文本，文件级检索更可控、引用零幻觉。

## 构建方式

- 借助开源工具 [book-to-skill](https://github.com/virgiliojr94/book-to-skill) 的「抽取文本 + 按需拆文件」思路，但针对法律做了适配：用 `pypdf` 按页顺序抽取（book-to-skill 默认的 pdf-inspector 会把后几编抽乱序），清理 PDF 插入的空格/页码标记，并用**条文序号锚点**（第一条 / 第二百零五条 / …）精确切成七编文件。
