# 速查卡 · 纳瓦尔宝典

【一句话锚】财富＝睡时也为你赚钱的资产；幸福＝当下无缺憾的平和。

【判断你卡在哪】
- 工资高却无被动收入 → 没持股权，仍是时间换钱
- 追逐热门却无独特专长 → 可被培训取代，无壁垒
- 只用工时/劳动力 → 没用零边际成本杠杆（代码/媒体）
- 纠结"等我还贷/换房就幸福" → 掉进欲望与享乐适应
- 爱比较、玩地位游戏 → 零和，损害内在平和
- 重大选择犹豫不决 → 答案多半是否定的

【反直觉结论】
1. 靠出租时间永远无法致富——必须拥有股权，用杠杆放大专长。
2. 越想"得到某物才快乐"，越不快乐；幸福是消除缺憾感，不是得到更多。
3. 努力被高估、判断力被低估；方向比速度重要，一个正确决策可赢一切。
4. 最强大的杠杆无需许可——写代码、出书、做媒体，让作品睡时也为你工作。
5. 退休不是 65 岁领退休金，而是"不再为想象中的明天牺牲今天"。

【行动顺序】
1. 找到社会需要、你做起来轻松自然的专长（做自己）。
2. 以个人名义担责，积累股权与声誉复利。
3. 用代码/媒体把专长产品化，规模化到睡觉时也赚钱。
4. 设高时薪，把时间留给高杠杆产出与思考。
5. 把健康排第一，练冥想与"接受"，用习惯习得幸福。

【纳瓦尔金句】
- "如果社会可以培训你，那么社会也可以培训他人来取代你。"
- "依靠出租时间是不可能致富的。你必须拥有股权。"
- "生活中所有的回报，无论是财富、人际关系，还是知识，都来自复利。"
- "幸福就是一种不需要主动作为的状态。当把'缺憾感'从生活中剔除时，幸福感就会油然而生。"
- "最终，你必须自己负起责任。救赎靠自己。"
