# 术语表 · 纳瓦尔宝典

- **财富 (Wealth)**：在你睡觉时仍能为你赚钱的资产（企业、股票、代码、媒体、出租房产）。≠金钱，≠地位。纳瓦尔定义财富为"睡觉时也能带来收入的企业和资产"。
- **金钱 (Money)**：社会信用符号，是把时间/财富相互转换的中介，具有调用别人时间的能力。
- **地位 (Status)**：在社会等级体系中的位置。零和游戏（你上别人就得下）；与"财富游戏"（正和）相对。
- **特定知识 / 专长 (Specific Knowledge)**：无法通过培训获得、无法被外包或自动化的独特能力，来自基因+环境+个人回应的组合，只能靠热爱与师徒制习得。
- **杠杆 (Leverage)**：放大产出的手段。三种：劳动力（他人为你工作）、资本（钱扩大决策影响力）、零边际成本产品（代码/媒体/书籍/电影，无需许可即可使用）。
- **股权 (Equity)**：企业部分所有权。没有股权就没有通往财务自由的路径；被动收入的来源。
- **责任 (Accountability)**：以个人名义承担商业风险。社会按责任大小、股权多少、杠杆效应回报你；双刃剑，但现代下行风险有限。
- **复利 (Compounding)**：不只存在于资本，也存在于人际关系、声誉、知识。所有回报都来自复利。
- **退休 (Retirement)**：纳瓦尔定义＝不再为了想象中的明天牺牲今天；方法：存够被动收入 / 开销降为零 / 做热爱到有钱没钱都无所谓的事。
- **幸福 (Happiness)**：纳瓦尔定义＝当下无缺憾的平和状态；是可习得的技能与主动的选择，≠积极心态，≠没有消极想法。
- **欲望 (Desire)**："你跟自己的约定——不得到想要的就不快乐。"是主动选择的不开心，痛苦的来源。
- **缺憾感 (Sense of Lack)**：对现实"还缺什么"的执念；剔除它，幸福感油然而生。
- **判断力 (Judgment)**：知道个人行为长期后果并据此决策的能力；杠杆时代被低估、比努力更重要。
- **心智模型 (Mental Models)**：有助于调取知识的简单方法（进化论、博弈论、微观经济学、可证伪性、反推法等）。
- **四种运气 (Four Kinds of Luck)**：不期而遇 / 坚持不懈创造 / 善于发现 / 打造独特个性让运气找你（最难得）。
- **单人游戏 (Single-player Game)**：生活本质是与自己竞争的内在游戏；幸福训练无需外界评判，区别于多人竞争的地位游戏。
- **正和游戏 vs 零和游戏**：长线游戏中人人互促致富（正和）；短线/地位游戏只在分蛋糕（零和）。
- **把自己产品化 (Productize Yourself)**："自己"＝独特性+责任感；"产品化"＝发挥杠杆+专长。致富的总结句。
