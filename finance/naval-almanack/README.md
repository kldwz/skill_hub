# naval-almanack

从《纳瓦尔宝典》（纳瓦尔·拉维坎特 思想，埃里克·乔根森 整理）蒸馏的财富与幸福知识 skill。当用户想理解复利/杠杆/特定知识/财富与幸福的底层逻辑，或引用纳瓦尔的观点时使用。

## 用途
从《纳瓦尔宝典》（纳瓦尔·拉维坎特）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《纳瓦尔宝典》—— 纳瓦尔·拉维坎特（初版约 2020 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/naval-almanack ~/.claude/skills/
```
