# reminiscences-stock-operator

从《股票作手回忆录》（埃德温·勒菲弗 著，记述杰西·利弗莫尔）蒸馏的投机交易知识 skill。当用户想理解趋势交易、关键点、仓位管理、市场心理、止损或引用利弗莫尔观点时使用。

## 用途
从《股票作手回忆录》（埃德温·勒菲弗）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《股票作手回忆录》—— 埃德温·勒菲弗（初版约 1923 年）
- 版权状态：**公版（可自由分发）**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/reminiscences-stock-operator ~/.claude/skills/
```
