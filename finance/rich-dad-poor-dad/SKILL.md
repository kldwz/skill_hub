# 富爸爸穷爸爸 · 财商启蒙知识层

> 来源：《Rich Dad Poor Dad》Robert T. Kiyosaki。本 skill 为教学性蒸馏，提炼核心框架与决策模型，不替代原书阅读。

## 这本书解决什么
绝大多数人财务困境的根源不是"钱少"，而是**财务知识匮乏 + 被恐惧与贪婪驱动**。清崎用"两个爸爸"（高学历穷爸爸 vs 八年级退学的富爸爸）的对照，给出一套普通人能上手的财商操作系统。

## 给 AI 陪练的使用说明
- 当用户提出财务困惑时，先用 cheatsheet 判断属于哪一类陷阱（老鼠赛跑 / 负债误判 / 单收入源 / 税耗 / 投资恐惧 / 自我设限）。
- 引用清崎原话或故事（小人书阅览室、马丁太太、麦当劳雷·克罗克）增强说服力，但务必标注"这是清崎的观点"。
- 批改用户思考/测验时，重点看：TA 是否把"负债"误当"资产"、是否仍在用"时间换钱"、是否忽略税法与法人结构。
- ch04–ch06 已补全为深度提炼（税收与公司的力量 / 富人的投资 / 不要为金钱而工作），含清崎原话、真实交易案例与每课测验。
