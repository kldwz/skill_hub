# 速查卡 · 富爸爸穷爸爸

【一句话锚】资产=钱进口袋；负债=钱出口袋。

【判断你卡在哪】
- 工资一涨开支就涨 → 老鼠赛跑
- 把房/车当资产 → 负债误判
- 只有工资一条收入 → 单收入源风险
- 税吃掉大半 → 没用公司力量
- 不敢投资怕亏 → 财务知识不足
- "我买不起/太迟了" → 自我设限

【行动顺序】
1. 画两张表（损益+资产负债），标现金流箭头。
2. 把增量收入先买资产，不升级消费。
3. 保留工作同时建资产项（房地产/股票/小企业）。
4. 有真实业务后用公司结构合法减税。
5. 学财务知识→定投资计划→再选产品。
6. 每月学一技能，用想要的生活反推资产目标。

【清崎金句】
- "富人获得资产，穷人和中产阶级获得他们以为是资产的负债。"
- "如果你发现自己在洞里，就别再挖了。"
- "工作只是面对长期问题的一种暂时的解决办法。"
- "财富是停止工作后还能活多久。"
