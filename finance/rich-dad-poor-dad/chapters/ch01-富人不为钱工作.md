# 第一课：富人不为钱工作

## 核心理念
人的行为被两种情感驱动：**恐惧（怕没钱）** 和 **贪婪（想要更多）**。大多数人陷入循环：起床→上班→付账→再起床→再上班，清崎称为"老鼠赛跑"（rat race）。他们以为"多挣钱"能消除恐惧和欲望，但钱满足不了，反而让欲望升级，于是工作更久。

> 富爸爸："大多数人都希望有一份工资收入，之所以会这样是因为他们有恐惧和贪婪之心。"

## 关键模型：老鼠赛跑循环
```
恐惧(没钱) → 去找工作 → 拿到钱(暂时消除恐惧) → 贪婪/欲望(想要更多) → 更高开支 → 恐惧回来 → 再工作...
```
驴追萝卜的隐喻：车夫（资本方）知道方向，驴（雇员）只追鼻子前的胡萝卜（工资/消费），永远在拉车。

## 原书故事（用于讲解）
- **9岁白干**：清崎和迈克给富爸爸的小店免费打工，富爸爸用"时薪从25美分到5美元"层层加价诱惑他们，测试能否抵制"用感情代替思考"。两人最终平静拒绝，富爸爸说"你们还有希望"。
- **小人书阅览室**：被拒工资后，两人发现马丁太太把没卖掉的漫画书封面撕半扔掉，于是免费收集这些书，在迈克家地下室办阅览室，雇妹妹当管理员，每人每周赚9.5美元——**不依赖雇主、钱在睡觉时也工作**。这是"让钱为你工作"的第一个实操。

## 可操作
1. 下次"想买东西/想换工作"的冲动出现时，先问：这是恐惧/贪婪在替我做决定，还是独立思考后的选择？
2. 把"建立资产"而非"提高工资"作为第一收入目标（见 ch02）。
3. 寻找"别人看不见的机会"——大多数人因忙着找稳定而看不见。

## 常见误区
- "我对钱没兴趣"＝回避真相，病得更重（清崎批评这类人）。
- 以为发财能解决恐惧——富人同样被恐惧支配（怕失去钱）。
- 用工资高低安排生活 ≠ 真正的生活。

## 给陪练的测验题示例
**Q**：小王月薪涨到3万，立刻贷款买了更好的车和房，他说"我现在更有钱了"。请指出他落入了哪个陷阱？
**A**：老鼠赛跑 + 把负债当资产。收入增加→支出同步增加；车/房是现金流出项（负债），不是资产。正确做法：先把增量收入买入资产（见ch02），让资产产生的现金流覆盖支出。
