# rich-dad-poor-dad

从《富爸爸穷爸爸》（罗伯特·清崎）蒸馏的财商启蒙知识 skill。当用户想理解资产与负债的区别、现金流、老鼠赛跑陷阱、ESBI 象限、税收与公司法人的力量，或需要财商启蒙、财务自由规划、引用清崎观点来批改自己的思考时使用。

## 用途
从《富爸爸穷爸爸》（罗伯特·清崎）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《富爸爸穷爸爸》—— 罗伯特·清崎（初版约 2000 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/rich-dad-poor-dad ~/.claude/skills/
```
