# common-stocks-uncommon-profits

从《怎样选择成长股》（菲利普·费雪）蒸馏的成长股选股与投资知识 skill。当用户想理解费雪的'闲聊法'、成长股定性分析、长期持有、管理层评估或引用费雪观点时使用。

## 用途
从《怎样选择成长股》（菲利普·费雪）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《怎样选择成长股》—— 菲利普·费雪（初版约 1958 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。
