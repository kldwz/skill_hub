# 一页速查 · 怎样选择成长股

> 来源：菲利普·费雪《怎样选择成长股》。本页为陪练/自查用速查卡，引用观点时标注"这是费雪的观点"。

## 一句话内核
用"闲聊法"做定性尽调 + 用"十五要点"筛公司 + 在好公司遇暂时麻烦时买入 + 除三种情形外长期抱牢 + 用"保守四要素"守本金。
（费雪观点：定性研究、长期持有、集中优质、管理层至上，胜过复杂数学与宏观择时。）

## 选股十五要点（速记）
- 上（市场/产品）：①市场潜力大 ②有持续创新意愿 ③研发真有效 ④销售组织强 ⑤利润率较高 ⑥靠降本维护利润率
- 下（人/管理/财务）：⑦劳资好 ⑧高管关系顺 ⑨管理有深度 ⑩成本会计扎实 ⑪行业独特能力 ⑫着眼长利 ⑬不轻易稀释股东 ⑭坦诚报忧 ⑮管理层诚信

## 买点三型（费雪观点）
- 买点 A：新产品/新厂试车超期、盈余暂挫、股价跌——麻烦属暂时即可买。
- 买点 B：短暂罢工/误判致股价恐慌下跌，几个月内可解。
- 买点 C：扩产利润跃升前夜，市场尚未反映。
- 共性：盈余即将改善，但展望还没推升股价。

## 卖出三理由（与价格无关）
① 买错了 ② 公司本质已变（十五要点退化）③ 有显著更好的标的。短期涨跌、大盘回档都不是理由。配"三年守则"。

## 保守投资四要素（缺一不可）
低成本/研发/财务稳健 → 人的因素（劳资/高管/深度）→ 行业投资特征 → 价格余地。

## 十不戒律（费雪观点）
五不：不买创业早期推销股 / 不因 OTC 交易排斥好公司 / 不因年报文笔好而买 / 不因高市盈率否定好公司 / 不因冷门而忽略。
另五不：不要过度分散 / 别因战争阴影不敢买 / 别被噪音干扰 / 别因短期波动动作变形 / 不要随波逐流。

## 组合与配置（费雪观点）
- 大部分资金→保守型成长股（龙头）；小比例→年轻高风险的成长股。
- 投入的必须是"真正多余的资金"（先留应急金、保保障、还确定性负债）。
- 不分红≠利空；看留存收益再投资回报。
- 长期通胀下，出色普通股优于高等级债券。

## 常见踩坑速查
追行业增速 / 忽视管理层与人 / 想宏观择时 / 因涨跌卖好公司 / 过度分散 / 把不分红当利空或高息当安全 / 用确定性支出买高波动股。

## 速记口诀
调研靠闲聊，筛选十五点；买在麻烦处，抱牢三年守；
卖看三理由，分散莫过头；管理层坦诚，才是真保守。
