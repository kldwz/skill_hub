# art-of-asset-allocation

从《资产配置的艺术》（戴维·M·达斯特 / David M. Darst）蒸馏的资产配置与长期投资组合管理知识 skill。当用户想理解资产配置、六维决策、量化工具、再平衡、行为偏差、资产类别、历史轮动、环境分析、配置矩阵或引用达斯特观点时使用。

## 用途
从《资产配置的艺术》（戴维·M·达斯特）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源

- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。
