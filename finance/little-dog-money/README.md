# little-dog-money

从《小狗钱钱》（博多·舍费尔）蒸馏的财商启蒙知识 skill。当用户想学习金钱观、储蓄投资习惯、引导孩子或自己建立财务自信，或引用舍费尔的框架（梦想储蓄罐、成功日记、养鹅理论）时使用。

## 用途
从《小狗钱钱》（博多·舍费尔）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《小狗钱钱》—— 博多·舍费尔（初版约 1999 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：
