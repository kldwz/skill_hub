# 小狗钱钱 · 财商启蒙知识层

> 来源：《小狗钱钱》（Bodo Schäfer / 博多·舍费尔）。本 skill 为教学性蒸馏，提炼原书核心框架、故事与决策模型，不替代原书阅读。所有观点均来自原书，未照搬其他作品。

## 这本书解决什么
大多数人财务困境的根源不是"钱少"，而是**从小没学过与钱打交道**，并被恐惧、贪婪和"缺钱才重要"的错觉驱动。舍费尔借一只会说话的狗"钱钱"，把一个 11 岁女孩吉娅从零开始学理财、并帮父母走出债务危机的过程写成故事，把"财务自由之路"里的硬规律变成了孩子也能上手的操作系统：明确愿望、建立自信、养鹅、量入为出、明智投资。

## 给 AI 陪练的使用说明
- 用户提出财务困惑时，先用 cheatsheet 判断属于哪类陷阱（无愿望 / 不自信 / 只试不做 / 拖延 / 负债误还 / 杀鹅消费 / 厌恶风险 / 忽视通胀）。
- 引用原书故事（达瑞、马塞尔、金先生的鹅、陶穆太太的地下室、爷爷奶奶怕风险）增强说服力，引用时务必标注"这是舍费尔的观点"（或借钱钱之口传达）。
- 批改用户思考 / 测验时，重点看：是否把"负债还清=目标"、是否"只试不做"、是否"杀掉自己的鹅"、是否把所有钱投进高风险、是否忽视通胀对现金的吞噬。
- 每章都配有测验题示例（Q+A），可直接用作陪练提问；鼓励用户先写"成功日记"再作答，建立自信。
