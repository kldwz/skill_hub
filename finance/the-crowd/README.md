# the-crowd

从《乌合之众》（古斯塔夫·勒庞）蒸馏的群体心理学知识 skill。当用户想理解群体心理、市场情绪、投资中的从众行为、人群非理性或引用勒庞观点时使用。

## 用途
从《乌合之众》（古斯塔夫·勒庞）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《乌合之众》—— 古斯塔夫·勒庞（初版约 1895 年）
- 版权状态：**公版（可自由分发）**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/the-crowd ~/.claude/skills/
```
