# 速查卡 · 穷查理宝典

【一句话锚】反过来想，总是反过来想；在能力圈内，等少数好球，然后下重注。

【反直觉结论】
- 想成功，先研究"如何失败"——规避愚蠢比追求聪明更可靠（农夫谚语：永远不去会死的地方）。
- "分散投资"在芒格眼中是"发疯的观念"；好投资往往高度集中，约 10 家而非 400 家。
- 股价下跌不是风险，永久亏损才是；波动是机会，便宜货正是在下跌中产生。
- 诚实不是道德装饰，而是"最好的策略"——省去记谎言的成本，积累难以摧毁的声誉。
- 你不必精通 100 种思维模型，掌握关键的几个（复利、误判、临界点、达尔文、冗余备份）即可拥有普世智慧。

【判断你卡在哪】
- 只用一种框架解释一切 → 铁锤人倾向（补多元模型）
- 总在追涨杀跌、随大流 → 社会认同 / 激励偏见（用检查清单）
- 重仓看不懂的热门 → 越过能力圈（归入"太难理解"）
- 每月频繁买卖、跑输大盘 → 没在"等好球"（坐等投资法）
- 用分散与波动掩盖无知 → 芒格：需要的是耐心而非大量行动
- 忽视失败清单、只空想成功 → 缺逆向思维

【行动顺序】
1. 画能力圈：列出真懂 / 太难理解。
2. 建心理误判检查清单，决策前逐条扫。
3. 用双轨分析：理性利益 + 潜意识心理。
4. 等"好球"：价格合理、护城河在变宽、管理层可靠。
5. 下重注、安坐，让复利不被打断。

【芒格金句】
- "反过来想，总是反过来想。"
- "在手里拿着铁锤的人看来，世界就像一颗钉子。"
- "你需要的不是大量的行动，而是极大的耐心。"
- "如果你想要说服别人，要诉诸利益，而非诉诸理性。"（富兰克林，芒格引述）
- "诚实是最好的策略。"（富兰克林，芒格引述）
