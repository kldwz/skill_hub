# 穷查理宝典 · 芒格思维与投资知识层

> 来源：《Poor Charlie's Almanack》（查理·芒格 Charlie Munger 思想，彼得·考夫曼 编）。本 skill 为教学性蒸馏，提炼核心框架与决策模型，不替代原书阅读。

## 这本书解决什么

大多数人决策失败，不是因为不够聪明，而是**只用单一学科思维、被心理倾向无声操控、在能力圈外下注、又总想"正向"追求成功**。芒格用一整套"普世智慧"——多元思维模型、人类误判心理学 25 条、逆向思维、能力圈、坐等投资法——给出一套普通人也能训练的理性操作系统。

## 主题速查索引
- 想避免单一视角 → ch02 + glossary「多元思维模型/铁锤人倾向」
- 想识别自身或他人的认知偏差 → ch03 + patterns「检查清单防误判」
- 想研究如何成功/避险 → ch04（逆向思维）
- 想判断"该不该投这家公司" → ch05 + ch06 + glossary「能力圈/护城河/坐等投资法」
- 想建立投资检查清单 → ch06 + patterns
- 想理解市场泡沫/经营本质 → ch07 + glossary「伦勃朗效应/竞争性毁灭」

## 给 AI 陪练的使用说明
- 当用户提出投资或决策困惑时，先用 cheatsheet 判断属于哪一类盲区（单一学科/心理误判/正向盲思/圈外下注/频繁交易/宏观幻象）。
- 引用芒格原话或故事（农夫谚语、联邦快递、泰德·威廉姆斯的击球区、喜诗糖果、苏联工人的玩笑）增强说服力，但务必标注"这是芒格的观点"。
- 批改用户思考/测验时，重点看：TA 是否只用一种思维模型、是否被激励偏见/社会认同操控、是否忽略"如何失败"的逆向清单、是否在能力圈外重仓、是否用分散与频繁交易自我安慰。
- 全书七章已覆盖传略、多元模型、误判心理学、逆向、能力圈、投资法、商业箴言，每章均含核心命题、模型、原书案例、可操作、误区与测验题。
