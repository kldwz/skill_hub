# 一页速查 · 聪明的投资者

> 来源：本杰明·格雷厄姆《聪明的投资者》。本页为陪练/自查用速查卡，引用观点时标注"这是格雷厄姆的观点"。

## 一句话内核
先不输，再求赢：以**价值与安全边际**为锚，用**纪律**对抗情绪，拒绝为故事付溢价。
（格雷厄姆观点：投资 = 透彻分析 + 本金安全 + 满意回报；其余皆投机。）

## 三类人先认领自己
- 防御型：省心安全优先 → 股债 50/50 + 定投 + 再平衡。
- 积极型：愿花精力 → 只在"价格远低于价值"处出手。
- 投机者：承认自己在赌，控制仓位，别伪装成投资。

## 市场先生（每天默念）
报价是**给你用的，不是指挥你的**。他抑郁（暴跌）时你该高兴能低价买，他狂躁（暴涨）时你该警惕。别被他牵着走。

## 安全边际三件套（格雷厄姆观点）
1. 价格显著低于内在价值；
2. 质量门槛撑起"价值"的可靠性（财务/派息/规模）；
3. 分散，把单笔误判变可承受的小概率损失。

## 防御型选股红线
规模大 + 财务稳 + 10 年连盈 + 20 年连派息 + 利润 10 年增≥1/3 + **PE≤15** + **PB≤1.5**，且 **PE×PB≤22.5**。
为"好公司"突破红线 = 付溢价 = 无安全边际。

## 积极型去哪捡便宜（格雷厄姆观点）
净流动资产折价股（市值 < 2/3 净营运资本）／特殊情况（并购清算分拆）／相对廉价股／便宜的增长股。

## 五个高频误区（见一个戳一个）
1. 把报价当价值 → 看内在价值与安全边际。
2. 把"长期持有好公司"当投资 → 没分析、价格荒谬仍是投机。
3. 为成长/品牌付无限高价 → 守 PE×PB≤22.5。
4. 择时战胜市场 → 用再平衡替代预测。
5. 盲信基金历史收益/顾问必胜承诺 → 买低成本与纪律，不买幻觉。

## 速记口诀
买：价值（分析过关）→ 便宜（有安全边际）→ 分散（控误判）。
避：投机、追高、择时、杠杆权证、盲信顾问、单押一只。
