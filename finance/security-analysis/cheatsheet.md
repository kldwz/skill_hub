# 速查卡 · 证券分析（格雷厄姆）

【一句话锚】买价相对内在价值的折扣，才是你的安全边际。

【反直觉结论】
- 市场短期是"投票机"（情绪定价），长期才是"称重机"（价值定价）——所以暴跌不等于你错了，暴涨也不等于你对了。
- "破净"（市价<账面）不等于便宜：账面可能虚高，真正底线看净流动资产价值与清算价值。
- 高盈利倍数/高增长故事反而更危险：漂亮数字若来自不稳定业务（如时尚周期），稳定性存疑，须打折。
- 高票息债券常是风险信号，不是"更划算"；保障倍数与资产覆盖才是安全真相。
- 安全边际不是"便宜 5%"，而是价格显著低于内在价值的厚缓冲——为你的误判和坏运气买保险。

【判断你卡在哪】
- 听消息/追热点下单 → 不是投资（缺透彻分析）
- 涨了就觉得安全、跌了就恐慌 → 被投票机牵着走
- 只看市盈率低或破净就买 → 忽略定性与清算底线
- 为"必翻倍"故事付高价 → 安全边际为零
- 凭债券名气/评级放松检验 → 忽视保障倍数

【行动顺序】
1. 区分投资/投机（ch02 三要件）。
2. 估内在价值：盈利折现 + 资产/清算价值（ch01/ch04/ch05）。
3. 算安全边际：股票=价值−买价；债券=盈利÷利息−1（ch06）。
4. 核对定量与定性是否相互支撑（ch04）。
5. 市场狂热查高估、恐慌扫错杀（ch07）。
6. 价格显著低于价值且有缓冲才下手，适度分散。

【格雷厄姆金句】
- "投资是经过透彻分析、保证本金安全并取得满意回报的操作；不符合的就是投机。"
- "安全边际的功能，是让投资者在估计错误或者运气不佳时，仍能避免严重损失。"
- "短期内市场是投票机，长期内是称重机。"
- "账面价值本身没有意义，除非有收益支撑。"
