# security-analysis

从《证券分析》（本杰明·格雷厄姆）蒸馏的价值投资知识 skill。当用户想理解内在价值、安全边际、债券与股票估值、财务报表分析或引用格雷厄姆观点时使用。

## 用途
从《证券分析》（本杰明·格雷厄姆）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《证券分析》—— 本杰明·格雷厄姆（初版约 1934 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/security-analysis ~/.claude/skills/
```
