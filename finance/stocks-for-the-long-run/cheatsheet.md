# 速查卡 · 股市长线法宝

【一句话锚】长期看，股票是保住购买力最可靠的资产；持有越久，它越安全。

【5 个反直觉结论】
1. 持有期越长，股票风险越低——持有超 17 年股票实际收益从不为负，20 年全部跑赢通胀；而债券因通胀不确定，长期实际风险反而更高。
2. 增长快 ≠ 收益高——标准石油(增长慢)1957–2012 赚得比 IBM(增长快) 多近一倍；中国增长最快、股票收益最差，拉美增长慢、收益最高。
3. 股息才是长期收益主轴——1871 年以来美股实际收益 6.48% 中，股息贡献 4.4%、资本利得仅 1.99%；价格=未来所有股息的现值。
4. 价值股长期跑赢成长股——低市盈率组 1000 美元变 80 万，高市盈率组仅 6.4 万；道指狗股策略年化约 12.6%。
5. 老人潮压不垮股市——全球视角下，新兴市场年轻工人的储蓄会买下退休者抛售的资产；退休年龄终将随寿命回升而非下降。

【关键数字】
- 美股 1802–2012 实际年化 ≈ 6.6%（三阶段 6.7%/6.6%/6.4%）
- 1802 年 1 美元股息再投资 → 2012 年 ≈ 1350 万美元
- 股票溢价：vs 长期国债 3%，vs 短期国债 3.9%
- 战胜概率：10 年 80%、20 年 90%、30 年+ 近 100%
- 全球 19 国实际收益算术均 4.6%、复合 5.4%（美国 6.2%）

【行动顺序】
1. 定真实持有期（到用钱还有几年）。
2. 期限长→以股票/全市场指数为核心；短→债券/现金。
3. 分红再投资，别消费掉股息。
4. 选股/基金看估值（高股息、低市盈率），戒高估值成长叙事。
5. 跨市场分散降风险，新兴市场按估值而非故事配置。
6. 遇大跌用"长期实际回报+时间分散化"稳住，不弃计划。
