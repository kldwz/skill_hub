# 第3章：股利是长期收益之源——价格等于未来所有股息的现值

## 核心命题
**长期看，股息是股东收益最重要的来源**。西格尔指出，1871 年以来美股平均实际收益率 6.48% 中，股息率贡献 4.4%、资本利得仅 1.99%。股票的内在价值不来自"盈利故事"，而等于**未来全部股息的现值**。理解这一点，就能看穿"低分红、高成长"叙事对长期回报的误导。

## 关键模型或框架
- **戈登股息增长模型（Gordon Model）**：P = d / (r − g)，股价由每股股息 d、股息增长率 g、必要收益率 r 决定；r = 无风险利率 + 通胀溢价 + 股票风险溢价。
- **盈利 vs 股息**：盈利是手段，股息（或等价现金分配）才是股东价值的目的；价格永远是对"未来股息"而非"未来盈利"的折现。
- **留存收益的去向**：偿债降本、再投资扩张、股份回购——回购通过减少流通股提升每股盈利与每股股息，等价于把现金以资本利得形式给股东。
- **股息政策等价性**：只要留存收益回报率 = 股权必要收益率，分红比例高低不改变股东总收益率（仅改变股息/资本利得的结构）。

## 原书案例或西格尔原话
- "股息对投资者积累财富的重要性不言自明……其作用远比通货膨胀、增长及估值水平的变换这些因素加起来还重要。"**这是西格尔引述罗伯特·阿诺德的观点（第10章开篇）**。
- 长期数据：1871–2012 平均实际收益率 **6.48%** = 平均股息率 **4.4%** + 实际资本利得 **1.99%**（资本利得几乎全由每股盈利增长产生，年均增 **1.77%**）。
- 派息率演变：二战前股息支付率 **71.8%**、股息收益率 **5.26%**；战后降至支付率 **49.6%**、股息收益率 **3.43%**；同期每股盈利增长率从 **0.69%** 升至 **2.8%**——总收益率几乎不变，只是收益结构从"股息"转向"增值"。
- 约翰·布尔·威廉姆斯（1938《投资价值理论》）："盈利只是达到目的的一种手段，我们不应将这一手段错认为目的。"

## 可操作
1. 评估长期收益，先看股息收益率与股息再投资，而非只看价格涨跌。
2. 理解低派息 ≠ 坏事：只要留存收益回报率不低于股权成本，回购/再投资与分红等价。
3. 勿被"盈利高增长"迷惑——盈利若不转化为未来股息或等价现金分配，对股东无价值。
4. 用股息再投资积累股份，是长期复利的核心机制（见 ch04 标准石油案例）。

## 常见误区
- "公司不分红=对小股东不好"：错。低派息若用于高回报再投资或回购，股东总收益不变（戈登模型等价性）。
- "看盈利就能估值"：错。对未来盈利折现会高估公司；正确做法是折现未来股息。
- "成长股不分红所以收益更高"：恰恰相反，低股息、高估值往往意味着更低长期回报（见 ch04）。

## 测验题示例
**Q**：公司 A 把盈利 100% 分红，公司 B 把分红率从 100% 降到 90% 并留存再投资，若留存回报率等于股权成本，谁的股东收益更高？
**A**：长期一样。按戈登模型，B 当前股息降到 90%，但留存推高未来每股股息增长率（本例约 1%），股价与总收益率（9% 股息 +1% 增值）与 A 完全相同。分红比例只改变收益结构，不改变股东总回报——前提是留存资金回报率不低于股权成本。
