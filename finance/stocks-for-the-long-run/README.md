# stocks-for-the-long-run

从《股市长线法宝》（杰里米·西格尔）蒸馏的长期投资与资产配置知识 skill。当用户想理解股票长期回报、时间分散化、股利、价值vs成长、长期持有或引用西格尔观点时使用。

## 用途
从《股市长线法宝》（杰里米·西格尔）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《股市长线法宝》—— 杰里米·西格尔（初版约 1994 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/stocks-for-the-long-run ~/.claude/skills/
```
