# most-important-thing

从《投资最重要的事》（霍华德·马克斯）蒸馏的周期、风险与第二层次思维投资知识 skill。当用户想理解马克斯的'第二层次思维'、钟摆理论、风险认知、周期定位或引用马克斯观点时使用。

## 用途
从《投资最重要的事》（霍华德·马克斯）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《投资最重要的事》—— 霍华德·马克斯（初版约 2011 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/most-important-thing ~/.claude/skills/
```
