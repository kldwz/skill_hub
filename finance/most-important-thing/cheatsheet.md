# 一页速查 · 投资最重要的事

> 来源：霍华德·马克斯《投资最重要的事》。本页为陪练/自查用速查卡，引用观点时标注"这是马克斯的观点"。

## 一句话内核
第二层次思维 + 低价买进（安全边际）+ 周期定位 + 逆向耐心 + 防御控险 = 长期不对称增值。
（马克斯观点：超越平均不可能靠和别人做相同的事；"避免致败投资，制胜投资自然会来"。）

## 三个根本问题（每看一笔投资先问）
- 价值：内在价值几何？我估得准吗？（马克斯：准确估计价值是根本出发点）
- 价格：相对价值是高还是低？"买得好"比"买好的"重要。
- 风险：永久损失概率多大？当前价格是否已蕴含过度乐观？

## 反直觉的结论（马克斯观点）
1. **高风险≠高收益**：更高风险只承诺"更广的结果分布"，不承诺更高实际收益；若高收益可靠，它便不是高风险。
2. **最重要的不是波动性风险，而是永久损失的可能**。
3. **人人都觉得没风险时最危险**——风险溢价消失，恰是风险最高之际。
4. **市场停在端点远多于中点**——牛熊三阶段提示：最后跟风者接盘，绝望者割肉。
5. **防御比进攻更可靠**——少亏是长期优异的基石；繁荣期达平均、衰退期超市场，已是宏大目标。

## 风险二分（别在底部砍仓）
- 账面波动的风险（底部小） ≠ 本金永久损失的风险（顶部大）。
- 广泛否定意见能把价格压到毫无风险；人人追捧的"最好资产"反而可能因无风险溢价而成最高风险。

## 逆向买入检查（马克斯）
- 现在是群体狂热还是群体绝望的极端？
- 我知道大众错在哪里、我的不同结论有何证据？
- 价格是否显著低于内在价值？是否留足错误边际？
- 我有无长期资本与心理承受力去接"下落的刀子"？

## 周期定位速记
不知去向何方，但知身在何处。他人无忧我小心，他人恐慌我积极。拒绝"这次不同了"。

## 避错清单
- 把"好公司"当"好投资"（忘价格）；用后视镜线性外推；押注宏观预测；
- 把短期好运当能力；高杠杆集中暴露致败风险；在周期极端向群体投降。

## 速记口诀
想深一层（第二层）→ 估准价值 → 低价买 → 看周期 → 抗心理 → 敢逆向 → 等耐心 → 守防御 → 少犯错。
