# 第6章：财务分析方法——同型与比率

## 核心命题
- **同型分析（结构分析）**：利润表各项 ÷ 收入；资产负债表各项 ÷ 总资产。
- **比率分析**三大类：盈利能力（效益）、营运能力（效率）、偿债能力。
- **效率 × 效益 = 总资产报酬率（ROA）**：判断盈利能力既要看效益（毛利率/净利率）也要看效率（周转率）。

## 关键模型或框架
- **盈利能力**：毛利率 = 毛利/收入；净利率 = 净利润/收入；ROA = 净利润/总资产；ROE = 净利润/股东权益。
- **营运能力（周转率 = 收入 ÷ 资产）**：总资产周转率、应收账款周转率（收入/应收，天数=365/率）、存货周转率（成本/存货）、固定资产周转率。分母理论用平均余额，书为简便用期末数。
- **短期偿债**：流动比率 = 流动资产/流动负债；速动比率 = (流动资产−存货)/流动负债。中国短期借款常借新还旧，扣短期借款后看更真实。
- **长期偿债**：利息收入倍数（利息保障倍数）= 息税前收益 EBIT / 利息；资产负债率（财务杠杆）= 总负债/总资产。中国上市公司平均约 45%，航空业可达 80%。

## 原书案例或肖星原话（标注"这是肖星的观点"）
- **新公司算例（原书数据）**：毛利率 28%、净利率 12%；存货周转率 6.2 次（约 58 天）、应收周转率 3.3 次（约 109 天）；流动比率 0.6、速动比率 0.5；扣除 5100 万短期借款后流动负债仅 800 万，真实流动比率 = 3670/800 = 4.6；EBIT = 520+100+130 = 750 万，利息保障倍数 = 750/130 = 5.8；资产负债率 = 5900/9520 = 62%。
- 美企流动比率破产前曾达 2，但中国多在 1~2。肖星提醒："如果你是一家中国公司的老板……很可能发现自己公司的流动比率比那些破产公司的还要低，难道自己要破产了吗？"——不会，因短期借款自我循环。（这是肖星的观点）
- 同型分析示例：新公司营业成本占收入 72%、三项费用合计 14%、所得税 2%、净利润 12%；资产中固定资产占 60%、应收占 14%。

## 可操作
1. 同型分析先画结构：成本占收入多少？固定资产占总资产多少？负债占比多少？
2. 算周转率看营运效率与回收风险（应收周转天数越长，坏账风险越大）。
3. 比较分析：与自身过去（趋势）、与同行标杆比，同型分析才能发挥最大功效。

## 常见误区
- 用长期资产/长期负债衡量长期偿债（错，变卖厂房还债=想关门，会计绝不用此法）。
- 直接时段数据 ÷ 时点数据（需取期初期末平均）。
- 照搬美国流动比率"标准 2"判断中国企业。

## 测验题示例（含具体算例）
**Q**：某公司流动资产 2000 万（其中存货 500 万），流动负债 1000 万，短期借款 600 万。求流动比率、速动比率，以及扣除短期借款后的"真实"流动比率。
**A**：流动比率 = 2000/1000 = 2.0；速动比率 = (2000−500)/1000 = 1.5；扣除短期借款后流动负债 = 1000−600 = 400 万，真实流动比率 = 2000/400 = 5.0。说明表面 2.0 不算高，但真正靠变现偿还的仅 400 万流动负债，短期偿债其实很安全——这正是肖星对中国企业的修正看法。
