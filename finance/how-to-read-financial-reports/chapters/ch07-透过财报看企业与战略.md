# 第7章：透过财报看企业、战略与"好公司"

## 核心命题
- 财务数据受三重因素影响：**行业大环境 + 企业战略定位 + 战略执行能力**。
- **好公司 = 赚钱的公司**：短期看正经济利润，长期看为股东创造价值。
- "赚钱"的及格线 = **加权平均资本成本 WACC**；经济利润 = (ROIC − WACC) × 投资资本。

## 关键模型或框架
- **五力图（波特）**：供应商议价能力、购买者议价能力、潜在进入者、替代品、行业内竞争——决定行业盈利能力，进而映射到财务：毛利率（竞争环境）、应收/存货（下游谈判力）、应付（上游谈判力）、固定资产占比（行业特征）、总资产周转率（管理水平）。
- **两大战略**：成本领先 = 低毛利高周转（效率制胜）；差异化 = 高毛利低周转（效益制胜）。执行不力则"两头都没得到"。
- **ROIC** = 税后营业净利润 / 投资资本（有息负债 + 股东权益）。
- **ROE** = 总资产报酬率 × 权益乘数；权益乘数 = 资产/股东权益 = 1/(1−资产负债率)。

## 原书案例或肖星原话（标注"这是肖星的观点"）
- **造纸 vs 彩电（2002）**：造纸毛利率 28%、应收占资产 14%、固定资产 62%；彩电毛利率 15%、应收 23%、存货 39%、固定资产 14%。肖星："毛利率其实反映了整个行业的竞争环境；应收账款和存货反映了企业和它下游购买方的关系；而应付账款则从侧面表现出企业上游供应商的谈判能力。"（这是肖星的观点）
- **刘洋公司**：收入年增 35%、净利年增 26%，但 ROIC 仅 10%/5%/6.6%。肖星发问："这样的财务数据不可谓不亮眼……可它是一个赚钱的公司吗？"（这是肖星的观点——要看是否超过资本成本。）
- **苹果 vs 华为（2017）**：苹果净利率 21.2% ≈ 华为 3 倍，总资产周转 0.6 次 ≈ 华为一半，呈差异化战略；最终 ROA 苹果 12.9% 高于华为 9.4%。肖星指出苹果用较低销售费用实现更快销售收款、更长占用供应商资金，体现产业链整合优势。（这是肖星的观点）

## 可操作
1. 看毛利率定战略类型，看周转率验证（低毛利高周转=成本领先；高毛利低周转=差异化）。
2. 判断"赚钱"用经济利润而非净利润：ROIC 是否 > WACC。
3. 股东提升 ROE 靠提高总资产报酬率，而非单纯加杠杆（借来的钱若拉低 ROA 则 ROE 反降）。

## 常见误区
- 把高净利润、高增长率当"好公司"（可能 ROIC 不及格）。
- 以为多借钱（高权益乘数）必提高 ROE（若总资产报酬率下降则无效）。
- 用毛利率判断管理水平（毛利率更多受战略/行业影响，净利率才综合反映管理）。

## 测验题示例（含具体算例）
**Q**：甲公司净利润 600 万，总资产 5000 万，股东权益 2000 万，有息负债 1500 万，权益资本成本（行业平均盈利）12%，债务利率 7%，所得税 25%。求 ROIC、WACC、经济利润，并判断是否为股东真正赚钱？
**A**：投资资本 = 1500 + 2000 = 3500 万；利息 = 1500×7% = 105 万，税后营业净利润 = 600 + 105×(1−25%) = 678.75 万；ROIC = 678.75/3500 ≈ 19.4%。WACC = 1500/3500×7%×(1−25%) + 2000/3500×12% = 2.25% + 6.86% = 9.11%。经济利润 = (19.4%−9.11%)×3500 ≈ 358 万 > 0，是真正为股东赚钱（超过行业平均）。另验证：ROE = 600/2000 = 30%，权益乘数 = 5000/2000 = 2.5，总资产报酬率 = 600/5000 = 12%，ROE = 12%×2.5 = 30% ✓。
