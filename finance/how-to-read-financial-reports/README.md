# how-to-read-financial-reports

从《一本书读懂财报》（肖星）蒸馏的财务报表阅读知识 skill。当用户想读懂资产负债表/利润表/现金流量表、理解三张表关系、分析企业财务健康度或引用肖星讲解时使用。

## 用途
从《一本书读懂财报》（肖星）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《一本书读懂财报》—— 肖星（初版约 2014 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/how-to-read-financial-reports ~/.claude/skills/
```
