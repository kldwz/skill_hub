# index-fund-guide

从《指数基金投资指南》（银行螺丝钉）蒸馏的定投与指数基金实战知识 skill。当用户想理解指数基金、估值定投、市盈率市净率估值、低估买入高估卖出或引用螺丝钉方法时使用。

## 用途
从《指数基金投资指南》（银行螺丝钉）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《指数基金投资指南》—— 银行螺丝钉（初版约 2017 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/index-fund-guide ~/.claude/skills/
```
