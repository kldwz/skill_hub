# 速查卡 · 指数基金投资指南

【一句话锚】价格大幅低于价值（低估）时定投，正常持有，高估卖出——循环往复。

【反直觉结论】
1. **越跌越要买（低估区）**：下跌不是风险，是便宜攒份额的"广积粮"机会；浮亏 15% 时同样钱能多买约 17% 份额。
2. **现金不是资产**：几十万活期存款长期被通胀侵蚀；能"生钱"的指数基金才是资产。
3. **看点数投资是刻舟求剑**：指数点数长期上涨（恒生 53 年涨 200+ 倍），死等"3000 点以下买"永远上不了车。
4. **好基金也不能一直定投**：贵了（盈利收益率 <10% 甚至 <6.4%）投资价值下降，应暂停/卖出，而非无脑坚持。
5. **最倒霉的时点开始定投也能赚钱**：1929 年大顶开始月定投美股，30 年年化仍 12.72%——纪律胜过择时。

【买卖纪律（盈利收益率法）】
- 盈利收益率 ≥10% → 定投
- 6.4% < 盈利收益率 <10% → 持有，不新增
- 盈利收益率 <6.4% → 分批卖出，换债基/理财
（H 股/恒生先打 9 折；周期/成长品种用 PE/PB 历史底部 + 博格公式）

【资产期限分层】
- 零钱/随取 → 货币基金（≈2%~3%）
- 1~3 年要用 → 债券基金（≈6%~7%，利率高选长期、低选短期）
- 3 年以上不动 → 低估指数基金（≈14%，长期最高）

【心态心法】
- 鹅：能下金蛋的资产别杀（未达卖出三条件就持有）。
- 双核：主业现金流是防御，定投低估指基是进攻。
- 高筑墙、广积粮、缓称王。
