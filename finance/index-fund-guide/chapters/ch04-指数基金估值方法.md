# 第4章：如何挑选适合投资的指数基金（估值方法）

## 核心命题
价值投资三要点（格雷厄姆）：价格围绕价值波动；要有能力圈判断价值；价格大幅低于价值（安全边际）才买入。对指数基金，靠四大估值指标（市盈率、盈利收益率、市净率、股息率）和两大策略（盈利收益率法、博格公式法）判断"价格是否低于价值"。

## 关键模型或框架
- **四大估值指标**：
  - **市盈率 PE = 市值 / 盈利（P/E）**。反映愿为 1 元盈利付多少钱；适用于流通性好、盈利稳定的品种（宽基大多符合）。陷阱：周期行业（证券、钢铁）盈利大起大落会现"市盈率陷阱"；亏损/高速成长期不适用。
  - **盈利收益率 = 盈利 / 市值 = 1/PE（E/P）**。约等于市盈率倒数；越高代表估值越低。例：PE=8 → 盈利收益率 12.5%。格雷厄姆常用，要求流通性好、盈利稳定。
  - **市净率 PB = 市值 / 净资产（P/B）**。从"买资产"角度衡量；适用于资产多为有形、长期保值、盈利不稳定的品种（证券、航空、能源、短期经济危机时的宽基）。与 ROE 相关：ROE 越高 PB 越高。
  - **股息率 = 现金分红 / 市值**。股息率 = 盈利收益率 × 分红率。股价越低股息率越高，熊市再投入效果出众。西格尔研究：标普500 1871–2012 实际收益 6.48%，其中股息 4.4%、资本利得 1.99%。
- **盈利收益率法（格雷厄姆）**——当前利率/收益水平下的阈值：
  - 盈利收益率 ≥ 10% → 分批投资（开始定投）。
  - 6.4% < 盈利收益率 < 10% → 坚定持有已买份额。
  - 盈利收益率 < 6.4%（≈债券基金长期平均收益）→ 分批卖出，换债券基金等。
  - 6.4% 源自国内债券基金长期平均收益率约 6.4%；10% 源自格雷厄姆"盈利收益率 >10% 且远高于无风险利率"。H 股/恒生需考虑分红税，盈利收益率打 9 折再用。
- **博格公式法（约翰·博格）**：
  - 年复合收益 ≈ 股息率 + 市盈率变化率 + 盈利增长率（三个变量）。
  - 盈利稳定 → 用快速版（盈利收益率法）；盈利高速增长 → 用博格公式；盈利不稳定/周期/无盈利记录 → 用博格公式变种（看市净率 PB）。
- **适用性小结**：价值/盈利稳定指数 → 盈利收益率法；成长指数 → 博格公式；周期指数 → 博格公式变种（PB）。
- **怎么查估值**：指数官网（中证指数、恒生指数）、金融终端（Wind/Choice）、每日估值推送（原书作者公众号）。指数基金可算估值，普通主动基金因持仓不透明无法算。

## 原书案例或螺丝钉原话
- 格雷厄姆："我们要用 0.4 元买价值 1 元的东西。"（安全边际核心） 这是格雷厄姆的观点（书中引用）。
- "盈利稳定的价值指数可以采用盈利收益率法来投资……成长指数可以使用博格公式法……周期指数可以使用博格公式的变种。" 这是银行螺丝钉的总结。
- 回测（2004–2015）：用盈利收益率策略定投上证50，年复合 29.27%；红利指数年复合 29.9%。这是银行螺丝钉用原书历史数据的回测。
- "盈利收益率法，其实就是博格公式的快速判断版本。" 这是银行螺丝钉的观点。

## 可操作
1. 先判断目标指数属于哪类：盈利稳定（宽基/红利）→ 用盈利收益率法；成长 → 博格公式；周期 → 看 PB。
2. 查该指数最新 PE/盈利收益率/股息率，对照阈值：盈利收益率 ≥10% 才值得开始定投。
3. 盈利收益率在 6.4%~10% 之间只持有不新增；<6.4% 分批卖。
4. 不适合盈利收益率的品种（如证券、创业板），用"PE/PB 处于历史底部区域"作为低估信号。

## 常见误区
- 用 PE 给周期行业估值——景气高点 PE 虚低、低点虚高，落入市盈率陷阱，应改看 PB。
- 用 PE 给亏损/高速成长期公司估值——盈利不稳定，PE 失真。
- 忽视流动性——小成交量股票 PE 再低也无参考意义（想买时出价会被自己抬高）。
- 把"低估"等同于"买了马上涨"——短期涨跌由供求决定，估值只在 3~5 年维度生效。

## 测验题示例
**Q**：某宽基指数基金当前盈利收益率为 8%，小王刚发年终奖，问现在该"开始定投""继续持有已买份""还是卖出"？若该指数 PE 为 12.5，算一下它的盈利收益率并验证是否自洽。

**A**：盈利收益率 8% 落在 6.4%~10% 区间，按原书规则应"坚定持有已经买入的基金份额"，不新增定投（可把钱转投其他盈利收益率 >10% 的品种）。验证：PE=12.5 → 盈利收益率 = 1/12.5 = 8%，自洽。注意 8% 未达 10% 起点，说明该指数当前不算便宜，不应新开仓；但未低于 6.4%，也不必卖，继续持有等更低估或更高估的信号。
