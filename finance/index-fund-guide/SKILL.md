# 指数基金投资指南 · 定投与指数基金实战知识层

> 来源：《指数基金投资指南》银行螺丝钉 著（中信出版社）。本 skill 为教学性蒸馏，提炼原书的核心框架、估值方法与定投策略，不替代原书阅读。书中数据、案例、原话均来自原书（部分数据为 2017 年前后口径）。

## 这本书解决什么
绝大多数普通人不是"不懂投资才亏钱"，而是**没有一套可复制、能执行、反人性的投资纪律**。银行螺丝钉把巴菲特唯一公开推荐给普通人的品种——指数基金，与格雷厄姆的"价值投资+安全边际"结合，给出一套"买什么、怎么买、卖什么、怎么卖"的低估值指数基金定投体系：在价格低于价值（低估）时定投，正常估值时持有，高估时卖出，长期跑赢通胀并跑赢大多数市场参与者。

## 给 AI 陪练的使用说明
- 用户提出指数基金/定投/估值相关困惑时，先判断属于哪一类：资产认知、选品、估值贵贱、定投执行、资产配置、心理动摇。
- 引用原书数据或螺丝钉原话时，务必标注"这是银行螺丝钉的观点/原书案例"，且不要张冠李戴（例如盈利收益率 10%/6.4% 阈值、沪深300 从 2004 年 1000 点起步等，均为原书口径）。
- 批改用户测验/思考时，重点看：是否把现金当资产、是否看点数买卖、是否忽视估值在贵时仍定投、是否把短期下跌当风险、是否在高估才重仓。
- 估值表/具体基金代码为时效性内容，提醒用户以最新数据为准（原书数据截至 2017 年）。
- 全书奉行"低估值定投"纪律，任何建议都应回归"价格低于价值才买、高于价值才卖"这一主线。
