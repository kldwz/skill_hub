# 第六章：价值陷阱与成长陷阱

## 核心命题
> 这是邱国鹭的观点：价值投资最需要的是坚守，最害怕的是坚守了不该坚守的。关键要避开**价值陷阱**——那些再便宜也不该买的股票，因其持续恶化的基本面会使股票越跌越贵。同时，最熊的熊股往往也是"成长股"，因为**成长陷阱比价值陷阱更常见**：高估值成长股的平均回报远不及低估值价值股。

## 关键模型或框架
**五类价值陷阱（共性：利润不可持续，便宜只是表象）**：
1. 被技术进步淘汰的（如数码相机发明后的柯达，股价从 90 元跌到 3 元多）。
2. 赢家通吃行业里的小公司（行业老大老二抢了老五老六饭碗，小股票再便宜也是陷阱）。
3. 分散的、重资产的夕阳行业（需求不增长 + 产能无法退出 + 无序价格战）。
4. 景气顶点的周期股（顶峰利润不可持续，应在高市盈率/谷底利润时买、低市盈率/顶峰利润时卖）。
5. 有会计欺诈的公司（成长股中更普遍）。

**常见成长陷阱（共性：成长不可持续，人性把未来想太美）**：
估值过高 / 技术路径踏空 / 无利润增长 / 成长性破产（现金流窟窿） / 盲目多元化 / 树大招风（低门槛成功招来蜂拥竞争，如团购一年出 3 000 家） / 新产品风险 / 寄生式增长（傍大款） / 强弩之末（过度外推过去高成长） / 会计造假。

> 这是邱国鹭的观点："各类价值陷阱的共性是利润的不可持续性，各类成长陷阱的共性是成长的不可持续性。成长本身并不是陷阱，但人性的弱点中对未来成长习惯性地过高预期和过高估值却是不折不扣的陷阱。"

## 原书案例或邱国鹭原话
- **柯达**：主业胶卷被数码相机淘汰，14 年前 90 元跌到 3 元多，标准价值陷阱。邱国鹭因此对技术变化快的行业特别谨慎。
- **团购/网景**：团购因门槛低，一两家成功后一年内中国出 3 000 家，谁也赚不到钱；网景浏览器巨大成功引来微软反击，下场凄凉。
- **《道德经》警示**："金玉之堂，莫之能守"——低门槛行业护城河窄而浅，城内若满是金银（高增长高利润），各路人马必攻入，引发恶性竞争。
- **管子**："不为不可成，不求不可得，不处不可久，不行不可复。"宁要有门槛的低增长，不要没门槛的高增长。
- **美国钢铁**：2 倍市盈率仍可从 2003 涨到 2008 中期翻 20 倍——说明"便宜的烂公司"未必是陷阱，但必须确认不是上述五类价值陷阱、且估值足够低。

## 可操作
1. 看到"便宜"先排查五类价值陷阱：技术是否会被淘汰？是否赢家通吃下的小公司？是否重资产夕阳分散行业？是否景气顶点周期股？有无会计欺诈迹象？
2. 看到"高成长"先排查成长陷阱：估值是否过高？技术路径是否可能踏空？是否无利润增长/成长性破产？是否寄生式/盲目多元化/强弩之末？
3. 周期股用市净率、市销率辅助，高市盈率（谷底利润）买、低市盈率（顶峰利润）卖，且必须结合宏观自上而下。
4. 用"门槛"检验成长：高增长必须有品牌、渠道、规模、资源、资质、核心技术等高门槛为后盾，否则易引恶性竞争。

## 常见误区
- 认为"市盈率低就是安全"。周期股低市盈率可能正是顶峰利润，反而是价值陷阱；需结合利润所处周期位置。
- 认为"买股票就是买未来，成长是硬道理"所以闭眼买成长股。邱国鹭指出最熊的熊股也常是"成长股"，高估值成长股平均回报不及低估值价值股。
- 把"暴发性成长"当可复制。暴发性成长本质不可预知、不可重复，像彩票——总有人中，但一定不是你。

## 测验题示例(Q+A)
**Q**：某光伏组件公司当前市盈率仅 6 倍，股价跌去大半，分析师称"估值极低、可以越跌越买"。用邱国鹭的框架判断它是否可能是价值陷阱，并说明应如何操作。
**A**：这是邱国鹭的观点框架下的回答：低市盈率不一定是便宜，要排查价值陷阱。光伏属政府大力扶持后产能过剩、技术路径多变（薄膜/晶硅之争）、且多为重资产——很可能落入"景气顶点周期股 + 技术淘汰 + 重资产分散行业"的组合，是典型价值陷阱，便宜可能是假象（利润将每况愈下）。操作上：①不盲目越跌越买；②周期股应看市净率/市销率，且要在高市盈率（谷底利润、行业出清）时考虑；③必须结合宏观供需，确认行业洗牌、落后产能出清、格局清晰后，才是"胜而后求战"的时点。若确认有反身性或基本面持续恶化，则应回避。
