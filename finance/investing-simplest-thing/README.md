# investing-simplest-thing

从《投资中最简单的事》（邱国鹭）蒸馏的 A 股价值投资实战知识 skill。当用户想理解便宜是硬道理、估值、定价权、逆向投资、行业格局或引用邱国鹭观点时使用。

## 用途
从《投资中最简单的事》（邱国鹭）蒸馏出的财商 / 投资知识 Skill。可作为 AI 陪练，按需回答关于该书核心观点、决策框架、真实案例与常见误区的问题。

## 来源
- 原书：《投资中最简单的事》—— 邱国鹭（初版约 2014 年）
- 版权状态：**受版权保护**（仅作个人学习使用，请勿随产品分发原文或整本摘要）
- 蒸馏流程：依据 book-to-skill 开放标准，从原著逐章蒸馏（框架 + 概念 + 测验），所有观点均归属原作者。

## 用法
直接复制到 Agent 的 skills 目录即可调用：

```bash
cp -R finance/investing-simplest-thing ~/.claude/skills/
```
